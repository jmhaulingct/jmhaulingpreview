JM HAULING WEBSITE — TEST VERSION

HOW TO TEST
1. Extract the ZIP file.
2. Open the JM-Hauling-Website folder.
3. Double-click index.html.
4. Test it on a computer.
5. To test on your phone, upload the folder to a free static host or use a local file-sharing method.

WHAT WORKS NOW
- Full responsive design
- Call and text buttons
- Service-area content
- Gallery and logo
- Google review link
- Form validation
- Multiple-photo selection
- Demo confirmation message

WHAT IS NOT LIVE YET

- The domain jmhaulingct.com is not connected.
